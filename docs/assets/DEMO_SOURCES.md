# Demo Audio Sources

The public website demo is rendered from two CC0 music files on OpenGameArt:

- Empacotatron by Fupi: https://opengameart.org/content/empacotatron
- Rhythm Garden by congusbongus: https://opengameart.org/content/rhythm-garden

Both source pages list the music license as CC0. Attribution is not required by
CC0, but the sources are credited here so the demo audio has clear provenance.
